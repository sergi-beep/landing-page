# Stimuli Digital - Landing Page

## Project Overview
Premium marketing landing page for Stimuli Digital, a B2B agency providing tech/development and operations/process optimization services.

## Target Audience
- C-level executives at B2B sales and marketing agencies
- Companies with 5M+ ARR
- 10-250 employees
- Countries with 30k+ GDP per capita

## Brand Guidelines

### Company Info
- **Name**: Stimuli Digital
- **Tagline**: Speed and efficiency in tech development and operations optimization
- **Key Differentiator**: 14 video case studies showcasing client results

### Design System
- **Design Philosophy**: Premium, modern, slick (inspired by Attio, Linear)
- **Vibe**: Trustworthy, professional, YC-backed startup aesthetic
- **Typography**: Prefer modern sans-serif fonts (Inter, Geist, system-ui fallbacks)
  - Original brand font: Sloth (Regular, SemiBold, Bold, ExtraBold)

### Color Palette
```
Primary:
- Brand Blue: #0066FF (Energetic Blue)
- Brand Sky: #38BDF8 (Clean Sky)
- Brand Black: #0F172A (Deep Black)
- Brand White: #FFFFFF (Clean White)

Additional (from style guide):
- Purple variants
- Magenta variants
- Mint Green variants
- Orange variants
- Dusty Green variants
```

### Logo Files
- Full logo: `/public/images/logo-full.png` (symbol + text)
- Symbol only: `/public/images/logo-symbol.png`

## Page Structure

### Sections
1. **Hero** - Bold value proposition with CTA
2. **Video Testimonials** - Showcase 14 case study videos
3. **Services** - Tech/Development + Operations/Process optimization
4. **Footer** - Contact info and links

### Call-to-Action
- Primary CTA: Book a consultation call
- Calendly link: https://calendly.com/sergi-feq/30min

## Technical Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Static export for optimal SEO
- **Repository**: GitHub - Stimuli-Digital organization

## SEO Requirements
- Server-side rendering enabled
- Optimized meta tags
- Semantic HTML
- Fast Core Web Vitals
- Mobile-first responsive design

## Development Guidelines
- Minimal, clean code
- No over-engineering
- Premium animations (subtle, sophisticated)
- Accessibility-first approach
- Performance-optimized images and assets

## Content Tone
- Professional and credible
- Results-oriented
- Confident but not arrogant
- Focus on speed, efficiency, and proven results
- B2B executive-appropriate language
